# Little Post · 此间小镇

绘画表达与小镇居民互动网页原型。完整网页源码、插画素材和 Windows 启动入口均可在 Releases 下载。

## 下载完整项目

[下载最新版本](https://github.com/jeanned77/Little-Post/releases/latest)

下载后先解压，再双击「启动小镇原型.cmd」。需要 Node.js 22.13 或以上版本，首次启动会联网安装依赖。

## 当前版本 · 2026-11-19

- 全屏低饱和小镇地图，支持拖动探索、缩放和暂停动效，创作画桌位于中央。
- 首次进入时由皮普带路，提供中英文切换。
- 自由绘画和形状拼贴支持自选颜色，拼贴支持拉伸、旋转与尺寸调整。
- 八位人形居民，皮普初始开放，其余在完成 2、4、6、8、10、15、20 幅画后解锁。
- 居民动态配有 15 张独立照片与对应文案，只出现已解锁居民的动态。
- 评论可插入七种基础表情，有机会收到另一位已解锁居民的回复。
- 树洞提供私密便签、纸团销毁与纸飞机寄远动效。
- 私人画作收藏支持爱心置顶、原地翻面，爱心随正面一起翻转。
- 邮寄、收藏、去向和回望选项使用统一风格的透明 PNG 插画。

居民对话与动态回复属于本地故事互动。收藏和解锁进度保存在使用者的浏览器中。发布包不包含个人收藏、登录密钥或本地私人数据。
