# Little Post · 此间小镇

绘画表达与小镇居民互动网页原型。本仓库通过 Releases 提供完整网页源码 ZIP，包含全部页面、最新素材和 Windows 启动入口。

## 下载完整项目

[下载最新版本](https://github.com/jeanned77/Little-Post/releases/latest)

下载后先解压，再双击「启动小镇原型.cmd」。需要 Node.js 22.13 或以上版本，首次启动需要联网安装依赖。

## 当前版本

- 低饱和小镇地图，建筑悬停分别触发风向标、画笔、信件、窗光、旗帜和小鸟互动。
- 八位人类居民，皮普初始开放，其余依次在完成 2、4、6、8、10、15、20 幅画后解锁。
- 人物悬停挥手、居民图鉴、邻友动态和随机居民分享。
- 私人画作收藏与翻面，中英文切换，圆角面板微阴影和边缘微光。

居民对话与邻友动态为本地故事演示。收藏和解锁进度保存在使用者的浏览器中，发布包不含个人收藏、登录密钥或本地私人数据。
